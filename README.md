## 1. 系统简介

ETF三因子监测系统是一个**桌面端Web工具**，用于监测A股市场7只核心ETF的"国家队资金"动向。系统通过**三因子模型**（量能因子 + 方向因子 + 份额因子）计算每只ETF的综合概率，帮助判断是否有大资金在买入。

## 2. 投资知识科普

### 2.1 什么是ETF？

**ETF（交易型开放式指数基金）** 是一种在证券交易所上市交易的基金。你可以像买卖股票一样买卖ETF。

- **沪深300ETF**：跟踪沪深300指数（A股最大的300家公司）
- **上证50ETF**：跟踪上证50指数（上海最大的50家公司）
- **中证500ETF**：跟踪中证500指数（中型公司代表）
- **中证1000ETF**：跟踪中证1000指数（小型公司代表）

### 2.2 什么是"国家队资金"？

"国家队"是市场对**汇金公司、证金公司、社保基金**等国有资金的俗称。这些资金体量巨大，常在市场低迷时买入ETF来稳定市场。

**如何识别国家队买入？**
- 国家队买入时，ETF成交量会**异常放大**（比平时多1.5~3倍）
- 国家队通常买入**沪深300ETF**（覆盖面最广）
- 多只ETF**同时放量**是更强的信号

### 2.3 三因子模型原理

本系统使用三个因子综合判断资金动向：

| 因子 | 权重 | 含义 | 通俗解释 |
|------|------|------|----------|
| **量能因子** | 50% | 成交量是否异常放大 | "今天买的人是不是特别多？" |
| **方向因子** | 20% | 价格是否在上涨 | "价格是不是在往上走？" |
| **份额因子** | 30% | 基金份额是否增加 | "基金规模是不是在变大？"（需akshare，当前暂未启用） |

**综合概率 = 量能概率×50% + 方向概率×20% + 份额概率×30%**

> 当前版本为**二因子模式**（量能70% + 方向30%），份额因子需要安装akshare库后启用。

### 2.4 信号等级说明

| 等级 | 图标 | 综合概率 | 含义 | 建议 |
|------|------|----------|------|------|
| 🔴 高确信 | 🔴 | ≥ 70% | 大资金买入信号强烈 | 重点关注，可考虑买入 |
| 🟡 中等 | 🟡 | 50%~69% | 有一定资金关注 | 继续观察 |
| ⚪ 正常 | ⚪ | < 50% | 无明显资金异动 | 观望 |

### 2.5 关键统计指标解释

| 指标 | 含义 | 好/坏判断 |
|------|------|-----------|
| **胜率** | 盈利交易次数 ÷ 总交易次数 | >50% 较好，>60% 优秀 |
| **最大回撤** | 从最高点到最低点的最大跌幅 | <5% 优秀，<10% 可接受 |
| **夏普比率** | 每承担1单位风险获得的超额回报 | >1 较好，>2 优秀 |
| **累计收益率** | 总盈利 ÷ 初始资金 | 正值即盈利 |

## 3. 快速开始

### 3.1 启动后端

**方式一：双击启动**
```
双击 etf-web/start.bat
```

**方式二：命令行启动**
```bash
cd etf-web
pip install flask flask-cors
python backend/server.py
```

看到 `Running on http://localhost:5000` 表示启动成功。

### 3.2 打开前端

用浏览器打开 `etf-web/frontend/index.html`

> 推荐使用 Chrome 或 Edge 浏览器，分辨率 ≥ 1440px

### 3.3 首次使用

1. 页面加载后会自动连接后端并获取数据
2. 点击 **🔄 刷新数据** 按钮获取最新分析
3. 浏览4个Tab页查看不同维度的信息

## 4. 功能详解

### Tab 1: 📊 仪表盘

显示7只ETF的信号卡片，每张卡片包含：
- **综合概率**（大数字）：当前信号强度
- **信号灯**：🔴高确信 / 🟡中等 / ⚪正常
- **因子拆解**：量能概率、方向概率
- **价格信息**：最新价、涨跌幅

顶部汇总栏显示：
- 高确信数量、中等信号数量
- 沪深300共振数量（4只沪深300ETF同时触发）

**点击任意ETF卡片** → 自动跳转到"详情"Tab查看该ETF的完整分析。

### Tab 2: 📈 详情

选择一只ETF后查看：
- **综合概率大卡片**：当前信号等级
- **三因子环形图**：量能概率、方向概率、综合概率的可视化仪表盘
- **趋势折线图**：近20天三条概率曲线的走势
- **历史数据表**：每日详细数据（收盘价、成交量、倍量、各因子概率）

### Tab 3: 📅 历史

- **热力图**：7只ETF × 20天的信号强度一览
  - 颜色越红 = 信号越强
  - 颜色越绿 = 信号越弱
- **日期切换**：◀ ▶ 按钮浏览不同交易日
- **当日详情**：选中日期的各ETF信号详情

### Tab 4: 💰 模拟盘

详见[第5章](#5-模拟盘使用指南)。

## 5. 模拟盘使用指南

### 5.1 什么是模拟盘？

模拟盘是一个**纸上交易系统**，让你在不使用真实资金的情况下练习ETF交易。系统会根据三因子信号自动生成买卖建议，你可以手动确认执行，也可以设置为自动交易。

**所有数据保存在浏览器本地（localStorage），不会上传到任何服务器。**

### 5.2 模拟盘界面

```
┌──────────────────────────────────────────────┐
│  总资产 ¥108,234  +8.23%  │ 现金 │ 市值 │...│  ← 资产总览
├──────────────────────────────────────────────┤
│         收益曲线（模拟权益 vs 基准）           │  ← ECharts图表
├──────────────────────┬───────────────────────┤
│  📋 当前持仓         │  💡 交易建议           │  ← 两列布局
│  - 510300 盈亏+3.2% │  🟢 买入 510050       │
│  - 510500 盈亏-1.1% │  🔴 卖出 512100       │
├──────────────────────┴───────────────────────┤
│  📜 交易记录（最近10条）                      │
├──────────────────────────────────────────────┤
│  累计收益 | 胜率 | 最大回撤 | 夏普比          │  ← 统计面板
├──────────────────────────────────────────────┤
│  [⚙️策略配置] [📥导出CSV] [📊导出JSON] [🔄重置]│
└──────────────────────────────────────────────┘
```

### 5.3 策略配置说明

点击 **⚙️ 策略配置** 按钮打开配置面板：

#### 💰 资金设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 初始资金 | 100,000元 | 模拟盘的起始资金 |

#### 📊 仓位控制
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 首次建仓比例 | 30% | 每次买入使用总资产的30% |
| 加仓比例 | 20% | 加仓时使用总资产的20% |
| 单只ETF上限 | 50% | 单只ETF最多占总资产的50% |
| 总仓位上限 | 80% | 所有持仓合计不超过80%（留20%现金） |

#### 🛑 止损设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 硬止损 | -5% | 亏损超过5%强制卖出 |
| 时间止损 | 10天 | 持有10天仍未盈利则卖出 |
| 信号卖出阈值 | 40% | 综合概率降至40%以下时建议卖出 |

#### 🎯 交易模式
| 模式 | 说明 |
|------|------|
| **手动确认**（推荐） | 系统生成建议，你点击"确认执行"才交易 |
| **半自动** | 卖出自动执行，买入需手动确认 |
| **全自动** | 买卖都自动执行（适合回测） |

### 5.4 交易信号规则

**买入信号（按优先级）：**
1. ≥3只ETF同时触发高确信 → 买入信号最强的那只
2. ≥2只沪深300ETF同时高确信 → 沪深300交叉验证
3. 单只高确信 → 可考虑买入
4. ≥2只中等信号 → 信号聚集

**卖出信号（按优先级）：**
1. 硬止损触发（亏损>5%）→ ‼紧急卖出
2. 信号消退（综合概率<40%）→ 建议卖出
3. 时间止损（持有>10天未盈利）→ 建议卖出

### 5.5 导出功能

- **📥 导出CSV**：交易记录导出为Excel可打开的CSV文件
- **📊 导出JSON**：完整统计摘要（含配置、持仓、交易记录、每日快照）

## 6. 常见问题

### Q: 为什么数据不更新？
A: 点击 **🔄 刷新数据** 按钮。数据来自腾讯财经API，非交易日（周末/节假日）数据不会变化。

### Q: 模拟盘数据会丢失吗？
A: 数据保存在浏览器localStorage中。**清除浏览器缓存会导致数据丢失**，建议定期导出CSV备份。

### Q: 如何重置模拟盘？
A: 点击模拟盘底部的 **🔄 重置模拟** 按钮。

### Q: 份额因子为什么是0？
A: 份额因子需要安装 `akshare` 库获取基金份额数据。当前版本暂未启用，使用二因子模式（量能70% + 方向30%）。

### Q: 后端启动失败怎么办？
A: 
1. 确认已安装Python 3.8+
2. 运行 `pip install flask flask-cors` 安装依赖
3. 检查端口5000是否被占用

### Q: 页面显示异常？
A: 
1. 确认浏览器窗口宽度 ≥ 1440px
2. 使用Chrome或Edge浏览器
3. 按F12打开开发者工具查看Console错误信息
